# 安全模型

在浏览器中执行的生成代码是可被攻击者触达的输入。本文档描述约束它的四个独立层次，按执行顺序排列。

## 第 1 层 —— 执行前的静态校验

`src/modules/pattern-validator/validator.ts` 在生成代码**运行之前**检查它：

| 检查 | 规则 |
|---|---|
| 分隔符配对 | 花括号、圆括号与方括号必须配对 |
| 必需的组合子 | 模式必须包含顶层的 `stack()` |
| 层标记 | `@agent:layer:<name>:start` 标记必须存在、成对且顺序正确 |
| 不安全代码 | 七组模式会被拒绝（见下文） |

### 七组不安全代码

| # | 分组 | 示例 |
|---|---|---|
| 1 | 网络或 Worker API | `fetch`、`XMLHttpRequest`、`WebSocket`、`EventSource`、`Worker`、`SharedWorker` |
| 2 | 浏览器全局对象 | `document`、`window`、`globalThis`、`navigator`、`location`、`localStorage`、`sessionStorage`、`indexedDB`、`caches` |
| 3 | 动态代码执行 | `eval`、`Function` |
| 4 | 动态 import | `import()` |
| 5 | 对象逃逸原语 | `constructor`、`prototype`、`__proto__`、`process` |
| 6 | 全局对象逃逸原语 | `Object`、`Reflect`、`Proxy`、`frames`、`opener` |
| 7 | 计算属性访问 | 跟在任意标识符、字符串字面量或闭合分隔符之后的方括号访问 |

有两点比这份清单更重要：

- **扫描前会剥离字符串与注释。** 一个在注释里含 `fetch` 一词的模式不会被拒绝；更重要的是，藏在字符串拼接里的载荷不会从朴素文本匹配下溜过去。
- **校验是门禁，不是 linter。** 不安全代码是阻断执行的*错误*，而不是警告。

## 第 2 层 —— 不透明源沙箱

运行时 iframe 创建方式为：

```js
iframe.setAttribute('sandbox', 'allow-scripts')
```

`allow-same-origin` **刻意缺失**。后果：

- 该 frame 的源是**不透明的**——它无法读取父文档、cookie、`localStorage` 或应用的会话。
- 浏览器无法把它当作同源，因此常见的沙箱逃逸捷径都不可用。
- 即使生成代码攻破了第 1 层，它也没有任何可用的环境权限。

应用自身的 CSP 与资源处理经过配置，使沙箱的世界与 UI 的世界保持隔离。

## 第 3 层 —— 带双向能力校验的版本化消息协议

父页面与沙箱**只**通过 `MessageChannel` 通信——而不是在共享 window handle 上用 `postMessage`：

- 消息带一个**协议版本常量**，因此版本不匹配的运行时快速失败，而不是半可用地运行。
- 一次**握手**建立通道；缺少握手会以显式错误超时，而不是让 UI 一直挂着。
- 每个请求都带**请求 id**，响应会与请求配对。
- 两端都按**能力白名单**校验收到的消息类型——沙箱不能要求父页面做任意事情，父页面也不会执行来自该 frame 的任意命令。
- 操作有**超时**（命令超时、用户手势超时），因此卡死的沙箱会表现为错误。

## 第 4 层 —— 服务端加固

`server/` 是一个小型 Node 服务。它施加：

| 控制项 | 取值 |
|---|---|
| 速率限制 | **20 次请求 / 分钟 / IP** |
| 限流表容量上限 | 10,000 条（因此限流器不会变成内存泄漏） |
| 请求体上限 | **64 KB** |
| Origin 白名单 | `ALLOWED_ORIGINS` 环境变量，默认回环来源 |
| 凭据 | **仅服务端**——API key 永不暴露给浏览器包 |

这个服务存在的确切理由，就是让 LLM 凭据永远不必出现在客户端代码里。

## 刻意不做的主张

- **沙箱不是安全性的形式化证明。** 它是纵深防御：静态校验、不透明源、协议层能力校验与服务端限制。每一层都被记录下来，以便被有意攻击。
- **mock 提供方（默认）把 LLM 从威胁模型中完全移除。** 改用真实提供方是一种需要主动选择的安全姿态变更，而不是默认行为。
- **不对任意第三方算子的音乐质量或安全性做任何主张。** 随附的算子目录是人工编写、经过审查的纯数据；算子不是可执行插件。
